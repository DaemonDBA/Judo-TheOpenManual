# Judo: The Open Manual
"Judo: The Open Manual" is a manual and companion guide to help govern both learning and teaching the sport of Judo.

### How to use this manual
There are three sections on the main repository:
* **content**: This folder contains the content of the manual in an "exploded" form, so that each page and section can be viewed ad-hoc.
* **releases**: In this folder, any "stable" releases of the manual will be gathered into a PDF to download a complete, packaged version.
* **sources**: Here, we include any sources used in the development of this manual, to give proper credit.
